# **App Name**: T-Track Sales

## Core Features:

- Client Management: Add, update, and manage client information, including key contacts.
- Contact Management: Store detailed information for contacts associated with each client.
- Opportunity Tracking: Track sales opportunities with details such as estimated close date, probability, and deal value in USD.
- Dashboard View: A dashboard providing an overview of all sales activities, opportunities, and client statuses.
- Data Persistence: Store all the app data in Firestore

## Style Guidelines:

- Primary color: Deep red (#B30000), based on the logo, to represent Telepsazio brand.
- Background color: Soft gray (#E0E0E0) for a clean and modern interface.
- Accent color: Darker gray (#424242) for elements requiring more focus.
- Font pairing: 'Inter' (sans-serif) for headlines and body text, offering a clean and modern readability.
- Use clear and simple icons for navigation and actions to improve usability.
- Maintain a clean and structured layout for easy information access and a user-friendly experience.
- Subtle transitions and animations on data updates for enhanced user feedback.
